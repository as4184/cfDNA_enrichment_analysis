# cfDNA Enrichment Analysis - FRAGILE Score Calculation

This repository provides a Python script to calculate the FRAGILE score from cfDNA fragment data. The FRAGILE score measures the improbability and probability of fragment properties like length and GC content.

## Script
- **python_FRAGILE_chunk_efficient.py**: Processes .bed files in chunks to calculate FRAGILE scores efficiently.

## Requirements
- Python 3
- Pandas
- Numpy
